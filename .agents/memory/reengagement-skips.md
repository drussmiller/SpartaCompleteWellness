---
name: Non-destructive re-engagement skips
description: User-confirmed rules for re-engaging after missed program weeks.
---

Re-engagement must preserve the original program start date and all posts, media, points, and history. It moves progress back by treating the latest completed missed weeks as automatic skips; the current partial week is never skipped.

**Why:** The user wants illness/absence weeks with zero activity excluded from progress and extended at the end of the program without rewriting the schedule or forfeiting work.

**How to apply:** Keep automatic Re-engagement skips separate from the four user-selected manual skips. Both sources are excluded from progress/stats, and posts in either source remain stored but must not appear in the Home feed.
